Introduction

Efficiently manage your property operations by creating and assigning tasks directly within Favhost. This workflow allows you to link tasks to specific listings, set schedules, and track progress across your portfolio.

Managing short-term rental properties requires meticulous coordination between hosts, cleaning crews, and maintenance teams. Favhost simplifies this by providing a dedicated Tasks module where you can centralize operational requests. By the end of this guide, you will know how to create a new task, associate it with a property listing, and assign it to a team member with specific scheduling and contact details.

Creating a New Task

The process begins in the Tasks section of the Favhost dashboard. Creating a task ensures that every operational requirement—from routine cleaning to emergency maintenance—is documented and tracked.

1

Access the Task Creation Form

Navigate to the Tasks tab in the main navigation menu. To start a new entry, click the + Create button located at the top right of the screen. From the dropdown menu, select Create Task to open the full configuration panel.

2

Select the Associated Listing

On the left side of the Create Task screen, you will see a list of your properties under Listings. Search for or scroll to the specific property that requires attention. Checking the box next to the listing title links the task to that property, ensuring the assigned staff knows exactly where the work needs to be performed.

Linking a task to a listing is crucial for reporting; it allows you to track the operational costs and history for each individual property in your portfolio.

Configuring Task Details and Assignment

After identifying the property, the next phase is to define the specifics of the work and who will perform it. The Task details section on the right contains all the necessary fields to ensure clear communication with your team.

3

Define Task Purpose and Description

Start by entering a descriptive Task Title, such as "Cleaning the room." Next, use the Type dropdown to categorize the work (e.g., Cleaning, Maintenance, Payment). In the Task description field, provide detailed instructions to guide the staff member, such as "Clean the room for the checkout."

4

Schedule and Assign the Task

Timing and accountability are key to property management. Use the Date and Time pickers to set the deadline. If the task is recurring, adjust the Repeat settings accordingly. Finally, enter the team member's name in the Assigned to field and provide their contact information, including Phone and Email.

Providing an email and phone number for the assignee allows Favhost to send automated reminders and updates, reducing the need for manual follow-ups.

5

Save and Confirm

Once all fields are populated, click the Create button at the top right of the panel. A green "Task created successfully" notification will appear at the top of the screen, and you will be redirected to the main Tasks view where your new entry is now visible.

Managing and Reviewing Tasks

With the task created, you can now manage it alongside your other property operations. The main Tasks page provides several ways to monitor progress.

Filtering and Viewing Tasks

The dashboard organizes tasks into categories like Overdue, Due this week, and Total tasks. You can click these headers to filter the list and focus on immediate priorities. Each task entry displays the property thumbnail, the assignee's name, and the scheduled time.

Accessing Task Details

For a deeper dive into any specific job, click on the task card. This opens a dedicated view showing the property address, the assignee's contact info, and the current status (e.g., "Pending" or "Scheduled").

Conclusion

By integrating task management directly with your property listings, Favhost ensures that every cleaning and maintenance request is clearly communicated and tracked. You can now confidently create operational tasks, assign them to team members, and monitor your entire portfolio's daily needs from a single dashboard. Your next step is to review your upcoming checkouts and start scheduling cleaning tasks to ensure your properties are always guest-ready.

FAQ

  • Can I assign one task to multiple property listings?

    No, each task is intended to be unique to a specific property to ensure accurate reporting and location-based instructions for your team.

  • Is there a limit to how many tasks I can create?

    Favhost does not impose a strict limit on task creation, allowing you to manage as many operational requests as your business requires.

  • Will the assignee receive a notification when I create the task?

    Yes, as long as you provide a valid email address or phone number in the task details, the system will trigger a notification to the assignee.

  • Can I change the status of a task after it is created?

    Yes, you can click on any existing task from the dashboard to edit its details or update its status as the work progresses.

  • How do I delete a task if it was created by mistake?

    You can manage existing tasks from the Tasks dashboard. Clicking into the task detail view generally provides options for editing or removal.

  • Can I attach photos or documents to a task?

    Yes, the task creation panel includes an "Attachments" section where you can upload relevant files or photos to guide your staff.

  • Can I set tasks to repeat automatically?

    Yes, use the "Repeat" dropdown menu during task creation to set daily, weekly, or monthly intervals for recurring needs like routine maintenance.
